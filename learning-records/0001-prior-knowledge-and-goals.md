# 学习者背景与核心学习目标确认

学习者已具备扎实的 TypeScript 与 AI Agent 开发经验，教学无需普及 Agent 概念或 TS 语法，可直接从 Cordis 微内核机制与 DeepSeek Harness 架构全景切入。核心目标是搞懂底层运行逻辑、独立开发完整 Capability Seam（三件套）以及掌握系统排查方法。

## Evidence
- 学习者在教学初始化对话中明确确认掌握 TS 与 Agent 开发基础。
- 提出了明确的能力交付诉求：搞懂项目运行原理、编写 Capability Seam、排查复杂问题。

## Implications
- 教学层级直接从架构级（Boot 装配、Cordis Context 树、Turn/Step 驱动流、Session Log 还原）开始。
- 练习侧重真实的 CLI 工具调用、源码定位与插件编写，保证高信息密度与实战性。
